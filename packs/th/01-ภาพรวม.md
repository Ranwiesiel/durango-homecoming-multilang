# 01 — ภาพรวม + คำศัพท์

## ตัวกรองสัตว์ (จาก UI ต้นทาง)

| เกาหลี | ไทย |
|---|---|
| 초식 | กินพืช |
| 육식 | กินเนื้อ |
| 길들이기 가능 | เลี้ยงได้ |
| 대형(크기 5+) | ขนาดใหญ่ (5+) |
| 고속 재생 1%/초 | รีเจนเร็ว 1%/วินาที |
| 출현 자리 없음 | ไม่มีจุดเกิดบนเกาะที่เข้าได้ |
| 갈 수 없는 섬에만 산다 | อยู่แค่เกาะที่ไปไม่ได้ |

## คอลัมน์ตารางสัตว์

| ต้นทาง | ไทย | ความหมาย |
|---|---|---|
| 이름 | ชื่อ | ชื่อสัตว์ (เกาหลีตามต้นทาง) |
| 성향 | นิสัยอาหาร | กินพืช/เนื้อ |
| 크기 | ขนาด | ตัวเลขขนาด + ชื่อขนาด |
| 레벨 | เลเวล | ช่วงเลเวลคอมแบต |
| 생명 lv60 | เลือดที่ lv60 | ที่ unstable_factor=1 |
| 공격 | โจมตี | ที่ lv60 / factor 1 |
| 방어 | ป้องกัน | ที่ lv60 / factor 1 |
| 공격주기 | คาบโจมตี | วินาทีต่อรอบ |
| 경직저항 | ต้านสะท้าน | blow/knock ตามข้อมูล |
| 서식 | ถิ่นอาศัย | เกาะที่พบ |

## สูตรตัวอย่าง (จากข้อมูลสัตว์)

หลายตัวมีฟิลด์ `f.life` / `f.atk` / `f.def` เป็นสตริงสูตร เช่น  
`(1.06 * ((combat_level + 24) ** 2)) * unstable_factor`  
ใช้ตอนคำนวณตามเลเวลคอมแบตและดัชนีไม่เสถียร — **อย่าเดาสูตรที่ไม่มีในไฟล์**
