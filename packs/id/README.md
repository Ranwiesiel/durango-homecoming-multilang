## Catatan dari sumber

- Di situs asli, klik baris hewan untuk melihat HP per bagian, efek hancur bagian, dan rumus
- HP/ATK/DEF mengacu **unstable factor = 1**
- Pulau **tidak dapat dijangkau** = tidak ada rute berlayar (koloni `op`, pulau kota `ur`, event, uji) — data lengkap tapi tidak bisa masuk
- Perkiraan kawanan pulau biasa: **1 kawanan per ~650 tile daratan**
- Pulau elite sintetis: peta setengah panjang · 1 bos + 1 kawanan support · **tanpa kawah** (fork)
- Drop butcher berupa rentang min–max · tiap bagian bisa terkunci skill gather
